# Mini To-Do Manager

A simple command-line to-do list built with Python.

## Features
- Add tasks
- View all tasks (numbered)
- Remove a task by number
- Shows the total number of tasks
- Handles invalid menu choices and task numbers

## Concepts used
Lists, `while` loops, `for` loops with `enumerate()`, `if/elif/else`, `input()`, f-strings

## How to run
1. Install Python 3
2. Download `todo_manager.py`
3. Open a terminal in that folder and run:

   python todo_manager.py
