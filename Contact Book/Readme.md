# Contact Book

A simple command-line contact book built with Python.

## Features
- Add a contact (name and phone)
- View all contacts (numbered)
- Search a contact by name (ignores capital letters)
- Delete a contact by name

## Concepts used
Lists, dictionaries, a list of dictionaries, `while` and `for` loops, `enumerate()`, `if/elif/else`, `input()`, f-strings

## How to run
1. Install Python 3
2. Download `contact_book.py`
3. Open a terminal in that folder and run:

   python contact_book.py
